# Rakta Seva Connect — Project Showcase Website

A responsive project showcase website created to present Rakta Seva Connect, an Android application developed as part of an internship project.

Since the main application is built for Android, this website provides a dedicated space to explore its purpose, features, interface screenshots, and available resources. It also makes the project easier to share and demonstrate through my resume and portfolio.
